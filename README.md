# PRM393_LAB

## Lab 1

Flutter project containing the Lab 1 exercises and the customized demo app.

Run it from the `Lab1` directory:

```powershell
flutter pub get
flutter run
```

## Lab 2

`Lab2/lab2.dart` contains all five Dart Essentials exercises in one file.

Run it from the repository root:

```powershell
dart analyze Lab2/lab2.dart
dart run Lab2/lab2.dart
```

## Lab 3

`Lab3/lab3.dart` contains five advanced Dart exercises covering repositories,
JSON, microtasks, stream transformations, and factory constructors.

Run it from the repository root:

```powershell
dart analyze Lab3/lab3.dart
dart run Lab3/lab3.dart
```

## Lab 5

Flutter movie detail application with navigation.

Run it from the `Lab5` directory:

```powershell
flutter pub get
flutter run
```

## Lab 6

Responsive movie genre browsing screen with title search, multiple genre filters, sorting, and a two-column layout from 800 px. See `Lab6/README.md` for screenshots and verification.

Run it from the `Lab6` directory:

```powershell
flutter pub get
flutter run
```
## Lab 7

Signup form with validation, keyboard focus management, password strength feedback,
and simulated asynchronous email availability checking. All app code is in
`Lab7/lib/main.dart` and can also be pasted into DartPad Flutter.

Run it from the `Lab7` directory:

```powershell
flutter pub get
flutter run
```

See `Lab7/README.md` for test cases, screenshots, and submission details.
